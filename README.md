# Financials

Personal financial context, organized so AI agents can read it for background when helping with planning, budgeting, or decisions.

## Structure

- [`goals/`](goals/) — financial goals (short and long term)
- [`vanguard/`](vanguard/) — Vanguard accounts and holdings
- [`capital-one/`](capital-one/) — Capital One accounts
- [`salary-warp/`](salary-warp/) — salary, compensation, and Warp payroll details
- [`reminders/`](reminders/) — recurring financial reminders and deadlines

Each folder has its own markdown files. Update them as account details, balances, or goals change — this repo is meant to stay current, not be a historical log.
